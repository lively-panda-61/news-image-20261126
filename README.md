## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` (1024×1024, under 1 MiB) to `$MAKEFUN_OUTPUT_DIR/entry.png`. Both runs write identical bytes. The image itself is rendered deterministically by `tools/render.py` (Pillow, local build tool only).
